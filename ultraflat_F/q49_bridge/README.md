# q49 to F to finite N: quantitative feasibility

This research subdirectory audits, but does **not** complete, OpenAI's Section 4–6 construction. For full reproducible exact-rational q49 certificates, see the separately packaged `certify_contraction.py` and `certified_jackson_cutoffs.py` from the prior auxiliary-polynomial work. The q49 values below were independently reproduced on 2026-10-10.

Run `python3 finite_n_audit.py --n 200 --h 2 --d 40` to inspect a necessary single-wave scale condition. This check is **not an impossibility theorem** for real Littlewood polynomials or alternative constructions.

See [FINITE_N_BRIDGE.md](FINITE_N_BRIDGE.md) for the proof, error-bar distinctions, and recommended mathematical agenda.
