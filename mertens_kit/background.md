## 1. 问题:纪录到底在证明什么

Mertens 函数 M(x) = Σ_{n≤x} μ(n)。Mertens 猜想 |M(x)| < √x 已于 1985 年被 Odlyzko–te Riele 证伪,但证明是存在性的:没人见过具体反例。

**振荡纪录**是这条研究线的一个分支:证明形如

    limsup_{x→∞} M(x)/√x ≥ C

的定理,C 越大纪录越强。注意它与「首个反例 x_min 的上界」(Kim–Nguyễn 2025: x_min < exp(1.96×10¹⁹))是**不同的目标**:纪录只描述无穷远处的振荡幅度,不给任何有限地址。本套件把纪录当作**方法验收**——同一套柱算法管线换上 Pintz/Saouter 有效核后,才是攻击 x_min 上界的主战场(README 第七节)。

为什么纪录可以「搜索」出来:由 Ingham 定理(第 3 节),只要**找到一个具体的 y** 使某个核加权零点和 h(y) > C,就立刻得到 limsup ≥ h(y) ≥ C 的严格定理。于是问题变成:如何构造让 h 尽量大的 y——这是一个计算搜索问题。

## 2. 数学骨架:显式公式与转子模型

由 Perron 公式与 1/ζ(s) 的极点结构,在 RH 下(记 ρ_k = 1/2 + iγ_k,y = log x):

    q(y) := M(e^y)/e^{y/2} ≈ Σ_k r_k·cos(γ_k·y − ψ_k)

其中振幅与相位由零点决定:

    r_k = 2/|ρ_k·ζ'(ρ_k)|,   ψ_k = arg(ρ_k·ζ'(ρ_k))

**转子图像**:每个零点是一个角速度 γ_k、长度 r_k 的旋转向量。q(y) 是它们水平分量之和。

关键数值(沙箱实算,已与 K–N 数据交叉验证):

- r₁ = 0.178283(K–N 的 alpha.txt 存的是 r/2,α₁ = 0.0891415 ✓)
- 前 50 个振幅之和 ≈ 0.957:**即使前 50 个转子完美同相也到不了 1**
- 典型涨落 σ = (Σr²/2)^{1/2} ≈ 0.17:纪录值 1.8+ 是深尾事件
- 振幅总和发散(~(log T)^{5/4},Gonek–Hejhal),但方差收敛——这条不对称性是整个柱算法的根基(第 5 节)。

## 3. Ingham 定理与核权重

不能直接操作发散的无穷和。Ingham (1942) 的定理(OtR 1985 使用的形式):取核加权的有限和

    h(y,T) = Σ_{γ_k<T} g(γ_k/T)·r_k·cos(γ_k·y − ψ_k),
    g(u) = (1−u)·cos(πu) + sin(πu)/π

则 **h(y,T) 的每个取值都是 q 的极限点**,故对任何找到的 y*:

    limsup M(x)/√x ≥ h(y*, T)

三个实践要点:

1. **T 以下的全部零点都必须进入求和**——不能只算对齐了的那些。这就是代码里 NEV=20000、T=γ_{20001}=18047.1 的含义;
2. 核 g 在 u→0 时 ≈ 1 − π²u²/2:低零点几乎不受惩罚,所以 T 越大、重要零点的权重越足(NEV=20000 时前 900 个零点的权重 ≥ 0.94);
3. 套件用的核形式取自 OtR 1985;**发表前需按 Ingham 原文核对常数与假设**(s05 的输出注记)。

有效权重 w_k = g(γ_k/T)·r_k(util.build_weights)。全预算 B = Σw ≈ 2.73(NEV=20000)——理论绝对天花板;实际能拿到多少由第 5 节的预算决定。

## 4. 相位对齐 = 格问题(与一次重要的审计)

让 h 大 ⟺ 让许多 γ_k·y ≡ ψ_k (mod 2π) 同时近似成立 ⟺ 非齐次联立丢番图逼近:

    找 y, m_k ∈ ℤ:γ_k·y − 2π·m_k ≈ ψ_k,  k ∈ 重块

经典编码(OtR 1985 → K–N 2025,s02 沿用):坐标取 √w_k·(γ_k·y − ψ_k − 2πm_k)·2^{NU},未知量 (y, m_k) 的整数组合构成格,目标向量为 √w_k·ψ_k·2^{NU}。这是一个 aCVP。

**权重审计(本线程的一个重要结论)**:坐标缩放 √w_k 意味着欧氏距离平方带权 w_k——恰是余弦损失 Σw(1−cosθ) ≈ ½Σw·θ² 在原点的正确 Hessian。1985 与 2025 两代管线都用对了;曾怀疑的「√r 权重错误(值 4–7 个数量级)」经原文核对撤回。残余的「代理税」只来自大角度饱和(1−cosπ=2 vs π²/2≈4.93),量级 e^{1.4}–e^{3.8},由收割层部分回收。

**为什么二次代理在重块上恰好准确**:大偏差最优分布下,重坐标(λw_k ≫ 1)的相位集中在 0 附近(近高斯,方差 1/(λw_k)),此处二阶 Taylor 精确;轻坐标(λw_k ≪ 1)近均匀——既不值得强制对齐,也是二次代理最差的区域。柱算法把它们剔出格,一举两得。

## 5. 稀有度记账:KL 账本、预算与边际匹配

把相位视为独立均匀(LI 启发式),h ≥ u 的稀有度由 Chernoff 速率控制:

    I(u) = sup_λ [λu − Σ_k log I₀(λ·w_k)],  逐坐标账本 d_k(λ) = λw_k·(I₁/I₀)(λw_k) − log I₀(λw_k)

**原始预算来源**:可表示的 y 范围给出候选空间的理想稀有度尺度。
`y ~ 2^{NU−16}` 时

    B_raw ≈ (NU − 16)·ln 2.

但 `B_raw` 不是 LLL/BKZ 已经搜索过的候选数。实际 checkpoint 定义

    L_H^ideal(B_eff) = h_H^observed

并以 `B_eff` 表示算法真正兑现的有效预算。NU1900 标定显示，增加 NU 会
同时增强格的各向异性；固定 block size 的约化近似罚可能恶化，从而抵消
大部分 `B_raw` 增长。两种预算不得混写。

**主动/被动分界**:在鞍点 λ 处,λw_k ≈ 1 是自然相变——λw≫1 的坐标值得进格主动对齐(每个 ~1.2–2.5 nats),λw≪1 的坐标对齐性价比极低,应留作随机余量。s02 的「KL 账本选主动集」= 按 w 排序取前 mH,mH 由预算匹配决定。

**头尾精确可加性**(Legendre 对偶):在全局鞍点处 I_H(u_H*) + I_R(u_R*) = I(u)。推论(边际速率匹配):给定有效候选数 M_eff,最优分割满足

    log M_eff ≈ I_R(u_R*)  (收割块的自然份额)

即:**格只支付重块的构造成本,枚举数量支付轻块的运气成本,两者之和贴住内禀稀有度墙**。这不是数值巧合,是速率函数下卷积的恒等式。

**收割定律**:M_eff 个近独立候选中,轻块+尾部的最大好运 ≈ σ_tail·√(2·ln M_eff)。沙箱实测 +0.04 ~ +0.08,与 σ≈0.01–0.03、M~10³–10⁴ 的预测一致。注意用 M_eff(去相关后的有效数)而非名义 M。

## 6. 柱算法:一句话与三个要点

**一句话**:只对「按 KL 账本值得主动对齐」的重坐标构造投影格;轻坐标与零点尾部在生成阶段完全自由、在评分阶段统一收割。

要点一(命名精确性):成功区域不是柱体,而是纤维化区域 ∪_{θ_H} {θ_H}×S_R(u−h_H(θ_H));**柱体 E_heavy × T_light 是统计最优的候选生成区域**。轻块不是不重要,而是「生成不约束、评分负责收割」。

要点二(与 K–N 的 b₁ 平移的区别):K–N 沿格内异常短向量平移邻居(回归词结构);柱算法是改变嵌入本身——删除轻坐标约束、降低格维度。两者叠加使用:s04 里 Babai 给基点,Y-向量(y-分量非零的短向量)生成 AP 族,轻块由全维评分收割。

要点三(工程收益与已验证的质量墙):LLL/BKZ 成本对维度和输入
bit-length 都敏感，而轻坐标进格几乎不换来对齐收益。固定 NU 的
`q=h_H/A_H` 不是可跨预算外推的约化税。当前反解
`L_H^ideal(B_eff)=h_H^real`；NU900 的 BKZ-20 三点给出 443–456 nats
预算税，但 m460 提升到 NU1900 后，wrapper/BKZ-20 的预算税增至
1025/1045 nats。

令 `D_ideal=A_H-L_H^ideal`、`D_obs=A_H-h_H`，定义

    kappa = D_obs/D_ideal = rho^2,
    B_eff ≈ B_raw - (mH/2) log(kappa).

m460 的 `kappa` 从 NU900/BKZ-20 的 `5.985` 增至 NU1900/wrapper 的
`70.107`。这项算法近似罚抵消了大部分新增 raw budget。`eta` 现在只是
事后观测量，不能再假定为 0.90；详见
`docs/archive/hurst1900_postmortem.md`。

**枚举工程守则**(踩过的坑):约化基里 y-分量为零的短向量是「纯关系向量」,平移它们不改变 y、只产生重复评分——候选生成必须用 Y-向量(s04 已内置)。

## 7. 精度经济学:为什么 Hurst 用一万位而我们只要六百位

相位误差 = δγ·y。要 cos 里的相位准到 ~10⁻³,**每个进入求和的零点**都需要

    γ 的十进制位数 ≥ log₁₀(y) + 8

预算换算:h 目标越高 → 理想稀有度越大 → y 越大 → 零点位数越多。下表
只估计 **理想候选空间和数值精度**，不承诺固定-beta LLL/BKZ 能兑现对应
`B_eff`：

| 目标                       | 需要 nats      | y 量级             | 零点位数                                  |
| -------------------------- | -------------- | ------------------ | ----------------------------------------- |
| 1.6383 (BT2015)            | ~513           | 10²²³           | ≥231(K–N 的 301 位够)                   |
| **1.826054 (Hurst)** | **~856** | **10³⁷²** | **≥380(必须重算,s01 生成 600 位)** |

**对旧主张的修正**：600 位十进制精度（仓库中以约 2000-bit Arb balls
保存）对 NU1900 产生的 y 做相位评分是足够的；这只是数值精度结论。
此前“柱算法 + BKZ 用约 900–1360 nats、以 1/20 弹药达到同一类定理”
把 `B_raw` 当成了可兑现的 `B_eff`，没有约化质量证据。m460/NU1900
实测 `B_eff` 只有 260.594（BKZ-20）或 280.799（wrapper），因此该性能
主张现已撤回。理想 m800 模型仍可越线，但要求 `B_eff>=771.015`、
`rho<1.862`；当前固定-beta 单-tour 路线没有达到这一条件。

**减负关键**(容易想错的点):只有 γ 需要高精度;α 和 ψ 线性进入振幅与相位偏移,~6 位就够——所以 K–N 的 alpha/beta 可直接复用,s01 只重算 γ。arb 的 `acb.zeta_zeros` 实测 0.01–0.10 秒/零点(457 位),两万个零点分钟级,且**输出自带严格误差球**——直接喂给 s05 的区间证书。

## 9. 证书等级与诚实边界

**四级证书**(严格性递增):

1. 浮点候选值(搜索输出)——不可发表;
2. 高精度复核(双 dps 重算一致)——旧沙箱 1.3624/1.3518 属此级;
3. **arb 球算术证书(s05)**——γ 严格球 + y 精确 + 区间运算,输出保证成立的 h_lo。数学上已是「区间枚举证明」;
4. 发表级——还需:① 核对 Ingham 定理原文的核形式/常数/假设(套件用 OtR-1985 形式);② α、ψ 换成独立重算的严格球(现为 K–N 301 位数据 + 保守误差 3×10⁻²⁹⁰,数值上远够,程序上宜独立);③ 引用规范(K–N Zenodo 10.5281/zenodo.10775723、Hurst 2018、OtR 1985)。

**启发式与严格的分界**:KL 账本、倾斜预测、收割定律、±预期区间——全部只用于**决定去哪搜**;最终定理只依赖「找到的具体 y + 球算术求和 + Ingham 定理」,不依赖任何概率假设。

**当前主要 blocker**：NU 增加时格不是均匀缩放，固定-beta
LLL/BKZ + 单个 Babai 的 `kappa` 会显著恶化。NU1900 m460 的 lift 与
scorer 已验证，`eta=0.1493`，因此 12 小时内直接升到 m800 的路线停止。
重新开放前需要先证明新 CVP/enumeration、多候选解码、预条件或更强约化
能在 m460 明显降低 `kappa`；不能只靠增加 MPFR 精度或重复同一 tour。

**不寻找具体 `y` 的第二路线**：极值非负三角多项式把 Anderson--Stark
原因子 `N/(N+1)` 强化为 `cos(pi/(N+2))`。这把规划目标降到约 700--800
个高权重零点的 `N≈8` 有限独立性证书。仓库已经实现真实零点小规模原型：
严格舍入误差进入内部 SVP/外部 CVP 半径，单/多对偶角色先批量过滤外部
目标，剩余目标再做精确 CVP。共同分母“整数锁定”不会因提高精度自动成立，
已从方案中删除。详见 `docs/extremal_independence_program.md`。
